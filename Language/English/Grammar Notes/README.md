# Grammar Notes

`Grammar Notes` stores practical English usage notes that help with reading, writing, and speaking without becoming a full grammar textbook.

## What Belongs Here

- compact notes on articles, countability, prepositions, word choice, phrasal verbs, modality, and register
- examples with Indonesian meanings when that helps recall
- learner-facing reminders drawn from reliable English grammar references

## What Does Not

- tense tables or long formal syntax rules
- general language-learning strategy
- vocabulary dictionary rows, which belong in `../Vocabulary`

## How To Use It

- start with `Practical Grammar Notes.md`
- add new notes only when one topic grows too large for the starter note
- keep examples short enough to scan in Obsidian

## Current Notes

- `Practical Grammar Notes.md`: beginner-to-intermediate English usage reminders with Indonesian notes.
