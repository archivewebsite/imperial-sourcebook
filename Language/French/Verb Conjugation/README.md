# Verb Conjugation

`Verb Conjugation` stores French verb pattern notes that support everyday sentence building.

## What Belongs Here

- high-frequency verbs grouped by useful pattern
- short conjugation reminders for recognition and production
- auxiliary choice notes for common compound forms

## What Does Not

- full tense tables
- grammar notes unrelated to verbs
- vocabulary rows that belong in `../Vocabulary`

## How To Use It

- learn the common verbs first: `être`, `avoir`, `aller`, and `faire`
- group new verbs by pattern instead of memorizing every verb separately
- add example sentences with Indonesian meanings

## Current Notes

- `Core Verb Patterns.md`: starter map for common French verbs and patterns.
