# Phrasebook - Idioms and Collocations

Learn these as ready-to-use chunks.

| Phrase | Indonesian Meaning | Context | Note |
| --- | --- | --- | --- |
| `Hallo.` | Halo. | neutral | Common greeting. |
| `Guten Morgen.` | Selamat pagi. | polite | Morning greeting. |
| `Guten Tag.` | Selamat siang; halo formal. | polite | Safe formal greeting. |
| `Guten Abend.` | Selamat malam. | polite | Evening greeting. |
| `Tschüss.` | Dadah. | casual | Informal goodbye. |
| `Auf Wiedersehen.` | Sampai jumpa. | polite | Formal goodbye. |
| `Ich heiße...` | Nama saya... | introduction | Common self-introduction. |
| `Freut mich.` | Senang bertemu. | introduction | Short for `Es freut mich`. |
| `Wie geht es Ihnen?` | Apa kabar Anda? | formal | With `Sie`. |
| `Wie geht's?` | Apa kabar? | casual | Familiar. |
| `Mir geht es gut.` | Saya baik-baik saja. | neutral | Standard answer. |
| `Entschuldigung.` | Permisi; maaf. | polite | To apologize or get attention. |
| `Bitte.` | Silakan; tolong; sama-sama. | flexible | Meaning depends on context. |
| `Danke schön.` | Terima kasih banyak. | polite | Everyday thanks. |
| `Kein Problem.` | Tidak masalah. | neutral | Response to apology or request. |
| `Wo ist...?` | Di mana...? | travel | Useful for directions. |
| `Ich hätte gern...` | Saya ingin... | polite request | Good for ordering. |
| `Zahlen, bitte.` | Minta tagihannya. | restaurant | Short and polite. |
| `Ich verstehe nicht.` | Saya tidak mengerti. | learner | Core phrase. |
| `Können Sie das wiederholen?` | Bisa Anda ulangi? | formal | Useful in class or service. |
| `Sprechen Sie Englisch?` | Apakah Anda berbicara bahasa Inggris? | formal | Travel phrase. |
| `Ich spreche ein bisschen Deutsch.` | Saya berbicara sedikit bahasa Jerman. | learner | Sets expectation. |
| `Alles klar.` | Oke; jelas. | casual | Shows understanding or agreement. |
| `Keine Ahnung.` | Tidak tahu. | casual | Informal. |
| `Bis später.` | Sampai nanti. | casual | Same day or later. |
| `Bis bald.` | Sampai segera. | neutral | Future meeting. |
| `eine Frage stellen` | mengajukan pertanyaan | study | Use `stellen`, not direct translation from English. |
| `einen Termin machen` | membuat janji temu | work, daily | Appointment phrase. |
| `Zeit haben` | punya waktu | daily | `Hast du Zeit?` |
| `Spaß machen` | menyenangkan | casual | `Das macht Spaß.` |
| `Lust haben` | ingin; berminat | casual | `Hast du Lust?` |
| `Bescheid sagen` | memberi tahu | daily | Very common spoken chunk. |
| `einen Fehler machen` | membuat kesalahan | study | Collocation. |
| `eine Entscheidung treffen` | mengambil keputusan | work | Collocation. |
| `ins Kino gehen` | pergi ke bioskop | social | `in das` contracts to `ins`. |
| `nach Hause gehen` | pulang | daily | Fixed phrase. |
| `auf Deutsch` | dalam bahasa Jerman | study | `auf` used for languages in this phrase. |
| `im Moment` | saat ini | neutral | `in dem` contracts to `im`. |
| `passt schon` | tidak apa-apa; sudah cukup | casual | Tone depends on context. |
| `Das kommt darauf an.` | Itu tergantung. | neutral | Useful discussion phrase. |
