# Phrasebook - Idioms and Collocations

Learn these as ready-to-use chunks.

| Phrase | Indonesian Meaning | Context | Note |
| --- | --- | --- | --- |
| `Bonjour.` | Selamat pagi; halo. | polite default | Use before asking for something. |
| `Bonsoir.` | Selamat malam. | polite default | Evening greeting. |
| `Salut.` | Hai; dadah. | casual | Use with familiar people. |
| `Enchanté.` | Senang bertemu Anda. | introduction | Masculine speaker form; feminine often `Enchantée`. |
| `Comment allez-vous ?` | Apa kabar? | formal | Safe with strangers. |
| `Comment ça va ?` | Apa kabar? | neutral | Less formal. |
| `Ça va.` | Baik; oke. | everyday | Can answer and ask. |
| `S'il vous plaît.` | Tolong; silakan. | polite | Formal or plural. |
| `S'il te plaît.` | Tolong. | familiar | With friends, family, children. |
| `Merci beaucoup.` | Terima kasih banyak. | polite | Everyday thanks. |
| `De rien.` | Sama-sama. | neutral | Response to thanks. |
| `Excusez-moi.` | Permisi; maaf. | polite | To get attention or apologize. |
| `Je suis désolé.` | Saya minta maaf. | neutral | Masculine speaker; feminine often `désolée`. |
| `Je voudrais...` | Saya ingin... | polite request | Softer than `je veux`. |
| `Où est... ?` | Di mana...? | travel | Useful for directions. |
| `Combien ça coûte ?` | Berapa harganya? | shopping | Everyday question. |
| `Je ne comprends pas.` | Saya tidak mengerti. | classroom, travel | Core learner phrase. |
| `Pouvez-vous répéter ?` | Bisa diulangi? | polite | Useful in class. |
| `Parlez-vous anglais ?` | Apakah Anda berbicara bahasa Inggris? | travel | Formal or neutral. |
| `Je parle un peu français.` | Saya berbicara sedikit bahasa Prancis. | learner | Sets expectation. |
| `À bientôt.` | Sampai jumpa lagi. | farewell | Near future. |
| `À tout à l'heure.` | Sampai nanti. | same day | Use when meeting again soon. |
| `Ça marche.` | Oke; bisa. | casual | Means agreement. |
| `Pas de problème.` | Tidak masalah. | neutral | Common response. |
| `C'est dommage.` | Sayang sekali. | neutral | Mild regret. |
| `avoir besoin de` | membutuhkan | collocation | `J'ai besoin d'aide.` |
| `avoir envie de` | ingin; merasa ingin | collocation | `J'ai envie de dormir.` |
| `avoir raison` | benar | collocation | `Tu as raison.` |
| `avoir tort` | salah | collocation | `J'ai tort.` |
| `faire attention` | berhati-hati; memperhatikan | collocation | `Fais attention.` |
| `prendre une décision` | mengambil keputusan | collocation | Natural verb-noun pair. |
| `rendre visite à` | mengunjungi seseorang | collocation | For visiting people. |
| `visiter un lieu` | mengunjungi tempat | collocation | For places. |
| `mettre la table` | menata meja makan | collocation | Household phrase. |
| `donner un coup de main` | membantu | idiom | Literally a helping hand. |
| `ça me dit` | saya tertarik; saya mau | casual idiom | `Ça te dit ?` means `Do you feel like it?` |
| `tout à fait` | sepenuhnya; benar sekali | neutral | Agreement or precision. |
| `n'importe quoi` | sembarangan; omong kosong | casual | Tone can be strong. |
| `petit à petit` | sedikit demi sedikit | neutral | Good learning phrase. |
| `de temps en temps` | dari waktu ke waktu | neutral | Frequency phrase. |
