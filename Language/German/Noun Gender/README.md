# Noun Gender

`Noun Gender` stores German noun lists with articles so gender is learned with the word.

## What Belongs Here

- beginner noun lists with `der`, `die`, or `das`
- gender pattern clues and exceptions
- Indonesian translations for review

## What Does Not

- general vocabulary dictionary rows
- verb notes
- long grammar explanations

## How To Use It

- learn every noun with the article and plural when useful
- mark exceptions that are easy to confuse
- use articles in examples, not bare nouns

## Current Notes

- `Beginner Noun Gender List.md`: starter German noun-gender reference.


## Review Rhythm

- Review when noun-gender examples repeat enough to need grouping, cleanup, or vocabulary routing.
- Keep gender patterns here and move plain word-list rows to vocabulary files.
