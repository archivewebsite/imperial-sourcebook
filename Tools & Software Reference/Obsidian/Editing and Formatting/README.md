# Editing And Formatting

`Editing and Formatting` stores Obsidian references for managing notes, vaults, files, titles, and storage behavior.

## What Belongs Here

- file format and storage behavior notes
- vault and note management references
- configuration-folder and symbolic-link notes
- title-quality guidance specific to Obsidian usage

## What Does Not

- general writing advice that belongs in `Learning & Skills` or `Personal Advice`
- active cleanup plans or routing tasks
- non-Obsidian editor documentation

## How To Use It

- keep each note focused on one Obsidian behavior or reference topic
- prefer short lookup notes over long mixed guides
- link stable entries from [[Tools and Software Reference MOC]]

## Review Rhythm

- Review when several notes start describing the same Obsidian behavior.
- Merge duplicate reference notes when their lookup purpose overlaps.
