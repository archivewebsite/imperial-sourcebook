This is a **personal or team knowledge-management workflow rule set**. Basically, it says: “Stop turning every app into a junk drawer,” which is apparently a lesson humanity must keep relearning.

It defines what each tool is allowed to be used for:

**01. Outlook is for communication, not task storage.**  
Emails should be messages, not a graveyard of “I’ll deal with this later” obligations. If an email contains an action, extract the task somewhere else.

**02. Todoist is the single source of truth for actions.**  
Anything that requires doing should live in Todoist. Not in your inbox, not in your memory, not in a sticky note that will become archaeological evidence.

**03. Obsidian is for notes, thinking, and meeting context.**  
Obsidian is where ideas, meeting notes, background context, decisions, and reasoning go. It is not the task list and not the file archive.

**04. OneDrive stores files.**  
Documents, attachments, spreadsheets, decks, PDFs, and other actual files belong in OneDrive.

**05. Confluence holds final shared documentation.**  
When something becomes polished, agreed, and useful for others, it goes into Confluence. This is the canonical shared reference, not a dumping ground for half-formed thoughts.

The overall point: each system has one job. Outlook communicates, Todoist tracks actions, Obsidian captures thinking, OneDrive stores files, and Confluence publishes final documentation. This prevents information from being scattered across five apps like a corporate confetti cannon.
