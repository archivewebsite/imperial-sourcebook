# Phrasebook

`Phrasebook` stores German phrases, idioms, and collocations with Indonesian meanings and context notes.

## What Belongs Here

- everyday German phrases for greetings, classroom, travel, food, and work
- collocations such as `eine Frage stellen` and `einen Termin machen`
- short idioms and fixed chunks worth recognizing

## What Does Not

- single-word vocabulary rows
- full dialogues
- grammar explanations without phrase examples

## How To Use It

- learn phrases as whole chunks
- keep `du` and `Sie` context visible
- add Indonesian meanings that explain function, not only literal meaning
