# Phrasebook

`Phrasebook` stores useful English phrases, idioms, and collocations with Indonesian meanings and context notes.

## What Belongs Here

- everyday English phrases for conversation, study, travel, and work
- idioms that appear often enough to be worth recognizing
- collocations that should be learned as fixed or semi-fixed chunks

## What Does Not

- single-word vocabulary rows, which belong in `../Vocabulary`
- long dialogue scripts
- grammar theory without phrase examples

## How To Use It

- review the phrase and Indonesian meaning together
- add short context labels such as `casual`, `polite`, `work`, or `study`
- avoid rare idioms unless they appear in a real source you want to remember
