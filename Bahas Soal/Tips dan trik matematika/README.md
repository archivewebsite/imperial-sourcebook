# Tips dan trik matematika

`Tips dan trik matematika` berisi catatan cepat yang dipisah per materi. Setiap file fokus pada cara mengenali pola soal, memilih jalan hitung pendek, dan mengecek hasil.

## Peran folder

- Menyimpan trik yang langsung membantu pengerjaan soal.
- Memisahkan materi berbeda ke file Markdown berbeda agar mudah dicari di Obsidian.
- Menjadi jembatan antara teori umum dan latihan di `Bahas Soal`.

## Indeks utama

Mulai dari [[Tips dan trik matematika MOC]].

## Prinsip isi

- Setiap trik harus punya syarat pakai.
- Rumus ditulis dengan MathJax Obsidian.
- Contoh dibuat pendek agar bisa dipakai sebagai pola ulang.
- Catatan sumber disimpan sebagai tautan biasa, sedangkan hubungan antarcatatan memakai wikilink.
