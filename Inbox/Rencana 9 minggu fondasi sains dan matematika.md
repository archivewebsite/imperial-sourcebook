# Rencana 9 minggu fondasi sains dan matematika

Periode: 28 April-29 Juni 2026.

Tujuan rencana ini adalah membangun fondasi matematika, fisika, dan kimia yang cukup kuat untuk belajar lanjut tanpa overload. Rencana ini tidak mengejar seluruh materi SMA atau awal kuliah dalam 9 minggu. Fokusnya adalah akar: numerasi, aljabar, grafik, satuan, gerak dasar, atom, ikatan, mol, dan kebiasaan belajar aktif.

Catatan waktu: jika rencana ini mulai dijalankan setelah 28 April 2026, jangan mengganti semua hari yang sudah lewat. Mulai dari sesi berikutnya dengan target lantai.

## Keputusan utama

- Fondasi lebih penting daripada cakupan.
- Matematika menjadi poros utama karena fisika dan kimia hitungan bergantung pada aljabar, rasio, pangkat, grafik, dan satuan.
- Setiap minggu hanya punya sedikit target inti.
- Setiap sesi harus memuat latihan aktif, bukan hanya membaca.
- Minggu terakhir dipakai untuk konsolidasi, mini-test, dan rencana lanjutan.
- Target resmi tetap kecil walaupun motivasi sedang tinggi.

## Prinsip belajar

1. Fondasi dulu, cakupan belakangan.
2. Matematika menjadi dasar untuk fisika dan kimia.
3. Target mingguan harus sedikit dan jelas.
4. Pakai target lantai, target normal, dan target bonus.
5. Utamakan soal, recall, worked examples, dan error log.
6. Turunkan beban saat berat; jangan menaikkan target saat terlalu semangat.

## Struktur mingguan

### Target lantai

Jika minggu sedang berat, cukup lakukan:

> 3 sesi x 15 menit per minggu.

Itu tetap dihitung berhasil.

### Target normal

Jika kondisi cukup stabil, lakukan:

> 5 sesi x 35-50 menit per minggu.

| Hari | Fokus |
| --- | --- |
| Senin | Matematika |
| Selasa | Fisika |
| Rabu | Matematika |
| Kamis | Kimia |
| Jumat | Review campuran |
| Sabtu | Opsional atau catch-up |
| Minggu | Istirahat dan review 10 menit |

### Target bonus

Jika sedang sangat semangat, tambah maksimal 1 sesi bonus. Jangan mengubah seluruh jadwal minggu itu.

Batas atas ini penting karena pola naik-turun sering muncul dari urutan: semangat besar, target berlebihan, gagal, sedih, lalu menghindar.

## Format satu sesi belajar

| Bagian | Durasi | Kegiatan |
| --- | ---: | --- |
| Mulai ringan | 5 menit | Buka materi dan tulis apa yang sudah diketahui |
| Contoh terbimbing | 10-15 menit | Pelajari 1-2 worked examples |
| Latihan aktif | 15-25 menit | Kerjakan soal yang mirip contoh |
| Error log | 5 menit | Catat 1-3 kesalahan |
| Penutup | 2 menit | Tulis langkah berikutnya |

Jangan mulai dari soal sulit. Untuk pemula, worked examples membuat cara berpikir terlihat dan menurunkan beban kerja memori.

## Template harian

```text
Hari ini saya belajar: ________
Target lantai: 15 menit
Target normal: 35-50 menit
Target bonus: maksimal +20 menit
Langkah pertama 2 menit: ________
```

Contoh:

```text
Hari ini saya belajar: persamaan linear
Target lantai: buka catatan dan kerjakan 2 soal
Target normal: 10 soal persamaan linear
Target bonus: 5 soal tambahan
Langkah pertama 2 menit: tulis 3x + 5 = 20 dan coba selesaikan
```

## Aturan anti-perfeksionisme

### Jika rencana terasa terlalu berat

Jangan tulis:

> Saya gagal.

Tulis:

> Beban hari ini terlalu tinggi. Saya pakai target lantai.

Target lantai harian:

- 15 menit.
- 2 soal.
- 1 contoh.
- 1 catatan kesalahan.

### Jika terlalu semangat

Jangan tulis:

> Mulai besok saya belajar 5 jam sehari.

Tulis:

> Saya catat ide itu, tetapi target resmi tetap kecil.

Semangat boleh dipakai untuk memulai sesi bonus, bukan untuk menaikkan seluruh standar hidup.

### Jika melewatkan satu hari

Jangan mengejar semua ketertinggalan.

Aturannya:

> Lewat satu hari = lanjut dari target lantai besok.

Bukan:

> Saya harus mengganti 3 jam yang hilang.

## Review mingguan

Setiap Minggu, jawab 5 pertanyaan ini selama 10-15 menit:

1. Apa 3 hal yang sekarang lebih saya pahami?
2. Apa 3 kesalahan yang paling sering muncul?
3. Topik mana yang terlalu berat?
4. Apakah target minggu ini terlalu besar?
5. Apa target lantai minggu depan?

Jangan membuat rencana baru setiap kali gagal. Cukup revisi kecil.

## Cara mengukur keberhasilan

Jangan ukur keberhasilan dari jumlah topik yang ditamatkan. Ukur dari indikator yang membuat belajar tetap berjalan.

| Ukuran sehat | Contoh |
| --- | --- |
| Konsistensi | Saya belajar minimal 3 kali minggu ini |
| Pemahaman | Saya bisa menjelaskan konsep tanpa melihat catatan |
| Retrieval | Saya bisa menjawab soal dasar dari ingatan |
| Error log | Saya tahu jenis kesalahan saya |
| Beban emosi | Saya tidak merasa harus sempurna untuk mulai |

## Dasar belajar yang dipakai

- Practice testing dan distributed practice dipakai sebagai fondasi utama karena belajar perlu recall dan pengulangan tersebar, bukan hanya membaca ulang.
- Worked examples dipakai di awal sesi karena pemula lebih terbantu oleh contoh terbimbing dan beban kognitif rendah.
- Target lantai, normal, dan bonus dipakai agar belajar tetap berjalan saat energi berubah.
- Review mingguan dan error log dipakai untuk self-regulated learning.
- Batas atas saat terlalu semangat dipakai untuk menghindari planning fallacy dan pola target berlebihan.
