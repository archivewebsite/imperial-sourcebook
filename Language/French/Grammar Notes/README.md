# Grammar Notes

`Grammar Notes` stores practical French usage notes for reading, listening, and sentence building.

## What Belongs Here

- compact reminders about articles, agreement, negation, questions, pronouns, contractions, and common prepositions
- short examples with Indonesian meanings
- source-backed notes that help avoid beginner mistakes

## What Does Not

- tense tables or long formal syntax rules
- verb pattern drills, which belong in `../Verb Conjugation`
- noun article lists, which belong in `../Noun Gender`
- vocabulary dictionary rows, which belong in `../Vocabulary`

## How To Use It

- start with `Practical Grammar Notes.md`
- keep notes practical and example-led
- split a topic only when it becomes too large for the starter note

## Current Notes

- `Practical Grammar Notes.md`: beginner French grammar reminders with Indonesian notes.


## Review Rhythm

- Review when repeated learner mistakes or examples need a clearer grammar note.
- Keep grammar references compact and move vocabulary rows back to the vocabulary folder.
