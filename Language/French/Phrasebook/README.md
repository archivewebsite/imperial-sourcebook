# Phrasebook

`Phrasebook` stores French phrases, idioms, and collocations with Indonesian meanings and usage context.

## What Belongs Here

- everyday expressions for greetings, classroom, travel, food, and conversation
- common collocations such as `avoir besoin de` and `faire attention`
- idioms and short fixed expressions worth recognizing

## What Does Not

- single-word vocabulary rows
- full dialogues
- grammar rules without phrase examples

## How To Use It

- learn phrases as complete chunks
- keep `tu` and `vous` context visible when relevant
- add Indonesian meanings that preserve the phrase's function, not only literal translation
