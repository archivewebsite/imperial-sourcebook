# Grammar Notes

`Grammar Notes` stores practical German usage notes for reading, listening, and sentence building.

## What Belongs Here

- compact notes on articles, cases, negation, prepositions, separable verbs, word order, and register
- examples with Indonesian meanings
- learner-facing notes based on reliable German grammar references

## What Does Not

- tense tables or long formal syntax rules
- full verb pattern work, which belongs in `../Verb Conjugation`
- noun article lists, which belong in `../Noun Gender`
- vocabulary dictionary rows, which belong in `../Vocabulary`

## How To Use It

- start with `Practical Grammar Notes.md`
- keep examples short and directly reusable
- add new notes only when a topic needs its own page

## Current Notes

- `Practical Grammar Notes.md`: starter German grammar reminders with Indonesian notes.


## Review Rhythm

- Review when repeated learner mistakes or examples need a clearer grammar note.
- Keep grammar references compact and move vocabulary rows back to the vocabulary folder.
