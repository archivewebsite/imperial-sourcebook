# False Friends and Common Mistakes

| Trap | Correct Meaning or Pattern | Example | Indonesian Note |
| --- | --- | --- | --- |
| `actuellement` = actually | `actuellement` means currently. | `Actuellement, j'étudie.` | `Actually` is closer to `en fait`. |
| `attendre` = attend | `attendre` means to wait. | `J'attends le bus.` | `Attend a class` is `assister à un cours`. |
| `assister à` = assist | `assister à` means to attend. | `J'assiste à la réunion.` | `Help` is `aider`. |
| `demander` = demand | `demander` means to ask. | `Je demande une réponse.` | `Demand` is stronger: `exiger`. |
| `librairie` = library | `la librairie` means bookstore. | `Je vais à la librairie.` | Library is `la bibliothèque`. |
| `collège` = college | `le collège` is middle school in France. | `Il est au collège.` | University is `l'université`. |
| `lycée` = university | `le lycée` is high school. | `Elle va au lycée.` | Do not translate as college. |
| `stage` = stage | `un stage` means internship or training period. | `Je cherche un stage.` | Theater stage is `la scène`. |
| `la lecture` = lecture | `la lecture` means reading. | `J'aime la lecture.` | Lecture can be `un cours` or `une conférence`. |
| `la note` = note only | `la note` can mean grade or bill. | `J'ai une bonne note.` | Context decides. |
| `le pain` = pain | `le pain` means bread. | `Je mange du pain.` | Pain is `la douleur`. |
| `le raisin` = raisin | `le raisin` means grape. | `Je mange du raisin.` | Raisin is `un raisin sec`. |
| `la recette` = receipt | `la recette` means recipe. | `Voici la recette.` | Receipt is `le reçu`. |
| `l'entrée` = main course | `l'entrée` is starter or entrance. | `Je prends une entrée.` | Main course is `le plat principal`. |
| `sensible` = sensible | `sensible` means sensitive. | `Il est sensible.` | Sensible is `raisonnable`. |
| `sympathique` = sympathetic | `sympathique` means nice or pleasant. | `Elle est très sympathique.` | Sympathetic is `compatissant`. |
| `déception` = deception | `la déception` means disappointment. | `Quelle déception !` | Deception is `la tromperie`. |
| `envie` = envy only | `avoir envie de` means to feel like or want. | `J'ai envie de dormir.` | Jealous envy is `la jalousie`. |
| `préservatif` = preservative | `un préservatif` means condom. | Use carefully. | Food preservative is `un conservateur`. |
| `j'ai allé` | Use `être` with `aller`. | `Je suis allé à Paris.` | Common auxiliary mistake. |
| `pas des amis` | Use `pas de` after many negatives. | `Je n'ai pas d'amis ici.` | Negative changes article. |
| `il fait pleut` | Use `il pleut`. | `Il pleut aujourd'hui.` | Weather phrases are fixed. |
| Pronouncing all `-er` endings as `-ay` | Only some forms sound like that. | `je parle` ends on an `l` sound. | Do not pronounce like `parlez`. |
| Using `tu` with every stranger | Use `vous` when unsure. | `Vous parlez français ?` | Safer in formal or unknown settings. |
| Forgetting adjective agreement | Match adjective to noun. | `une petite maison` | Agreement matters in writing. |
