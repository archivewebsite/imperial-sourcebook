# REVIEW

Use this checklist quarterly, or sooner when the vault starts hiding useful material.

## Quarterly Checklist

- Review `Inbox/` for complete notes that can move into existing Sourcebook buckets.
- Review `Clippings/` for imported source material that can be cleaned, distilled, or routed.
- Look for duplicate or near-duplicate titles using case-insensitive and punctuation-insensitive comparisons.
- Expand, route, or remove stale stubs that no longer have a clear purpose.
- Check high-value notes for broken image embeds or missing attachment references.
- Review `TAGS.md` for tag drift, unused recurring tags, or new tags that should be documented.
- Refresh folder READMEs when actual note placement no longer matches the written guidance.
- Confirm new buckets still earn their place and do not duplicate an existing documented folder role.

## Stop Conditions

- Do not reorganize notes just to satisfy the checklist.
- Do not backfill tags, metadata, citations, or templates unless the review task explicitly asks for that work.
- Prefer a small follow-up list over a broad cleanup pass when note meaning is ambiguous.
