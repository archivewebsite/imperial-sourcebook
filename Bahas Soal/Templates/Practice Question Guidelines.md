# Practice Question Guidelines

These guidelines capture patterns from the example folders:

- `Inbox/contoh soal penalaran matematika`
- `Inbox/contoh soal pengetahuan kuantitatif`

Treat those folders as references for good practice-question style. Do not copy them as templates.

## What The Examples Do Well

- They label each question with `Materi`, which makes mixed-topic practice easier to review.
- They use realistic contexts instead of abstract calculations only.
- They use concise answer choices with clear A-E formatting.
- They include multiple UTBK-style formats, not only ordinary multiple choice.
- They use tables, diagrams, or statement lists when those make the reasoning clearer.
- They keep the question stem focused on one decision or computation.

## Supported UTBK-Style Formats

Use these formats when they fit the skill being tested:

- `Pilihan Ganda`: five options A-E with one correct answer.
- `Isian Singkat`: no options; the student supplies the answer.
- `Benar/Salah`: a table of statements to judge.
- `Kecukupan Data`: statement (1), statement (2), then standard sufficiency choices.
- `Pilihan Pernyataan`: numbered statements followed by combination choices such as "1, 2, dan 3 benar".
- `Paket Stimulus`: one stimulus followed by several related questions.

## Question-Writing Rules

- Use clear Indonesian.
- Put the context before the mathematical task.
- Avoid unnecessary names, numbers, or story details.
- Keep units explicit.
- Use display math for longer expressions.
- Use `Materi` labels when the file mixes topics.
- Keep answer choices parallel in length and form when possible.
- Build distractors from common mistakes, not random values.
- Do not include answers in student-facing files.

## Paket Stimulus Rules

- Start with a clear instruction such as `Perhatikan stimulus berikut untuk menjawab soal nomor ...`.
- Keep all questions tied to the same stimulus.
- Mix formats only when the stimulus supports them.
- If a question can be answered without the stimulus, move it to `Kuis` or `Set`.
- Put tables directly in Markdown when possible.
- For diagrams or images, store the asset under `Attachments/` and include useful alt text.

## Drill Rules

- Train one micro-skill only.
- Keep the item shape repetitive enough to build speed.
- Use short questions.
- Set a realistic `Target kecepatan`.
- Use a compact `Kunci` companion file unless full reasoning is needed.
