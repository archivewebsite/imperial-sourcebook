# TAGS

This file is the canonical tag registry for Imperial Sourcebook. Tags should improve retrieval without duplicating the folder map.

## Roots

- `subject/`: topic or domain tags, such as `subject/math`, `subject/language`, or `subject/design`.
- `type/`: note-form tags, such as `type/concept`, `type/clipping`, `type/soal`, `type/worked-example`, `type/moc`, `type/stub`, or `type/cheatsheet`.
- `status/`: lifecycle tags, such as `status/stub`, `status/draft`, `status/review`, or `status/evergreen`.
- `level/`: learning-depth tags, such as `level/beginner`, `level/intermediate`, or `level/advanced`.

## Rules

- Add a tag here before using it as a recurring convention.
- Keep tags lowercase and use hyphens for multiword names.
- Prefer one useful tag over several decorative tags.
- Do not add tags to old notes retroactively unless a dedicated tagging pass asks for it.
- Do not use tags to mirror every folder name; folder placement remains the primary structure.
