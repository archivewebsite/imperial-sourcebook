# Git

`Git` stores version-control command references and Git workflow notes.

## What Belongs Here

- Git command cheatsheets
- Git workflow examples
- version-control concepts that are primarily lookup references

## What Does Not

- active repository plans or project-specific Git history
- broad software-engineering mindset notes
- GitHub automation prompts that belong in `D:\Imperial Records\Labs\AI\Prompt`

## How To Use It

- keep command examples close to the command they explain
- prefer readable command titles and concise lookup notes
- link the strongest references from [[Tools and Software Reference MOC]]

## Review Rhythm

- Review when Git notes duplicate command explanations.
- Merge overlapping command references only after preserving unique examples.
