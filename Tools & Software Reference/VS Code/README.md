# VS Code

`VS Code` is reserved for stable Visual Studio Code reference notes.

## What Belongs Here

- editor settings and keyboard shortcut references
- extension notes that are useful beyond one project
- reusable VS Code debugging or workflow guidance

## What Does Not

- project-local editor setup that belongs with the project
- general CLI or Git guides
- AI model or prompt experiments

## How To Use It

- add notes here when VS Code material becomes reusable reference
- split extensions or debugging into child folders only after repeated notes justify it

## Review Rhythm

- Review when VS Code notes start repeating around setup, extensions, or debugging.
