# CLI

`CLI` stores command-line and terminal references that are useful across projects.

## Current Buckets

- `Git`: Git commands, workflow notes, and version-control cheatsheets.

## What Belongs Here

- command-line cheatsheets
- reusable terminal workflows
- version-control references
- tool commands that are stable enough for lookup

## What Does Not

- one-project setup notes that belong in that project
- AI agent workflow experiments that belong in `D:\Imperial Records\Labs\AI`
- broad learning reflections about programming or engineering

## How To Use It

- group command references by tool
- keep examples practical and concise
- move command guides here when they stop being learning-in-progress

## Review Rhythm

- Review when command notes repeat or when a tool deserves its own child folder.
