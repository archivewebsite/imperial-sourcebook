# Tools & Software Reference

`Tools & Software Reference` stores stable guides for editors, command-line tools, developer utilities, and software workflows.

## Current Buckets

- `Obsidian`: vault behavior, note-management reference, and Obsidian-specific formatting or storage notes.
- `CLI`: command-line tools, terminal workflows, and command cheatsheets.
- `VS Code`: editor guidance and reusable VS Code setup or usage notes.

## What Belongs Here

- Obsidian guides, vault mechanics, and editor reference material
- CLI, Git, terminal, and shell command guides
- VS Code references that are useful beyond one project
- compact software cheatsheets meant for lookup

## What Does Not

- active coding projects that belong in `D:\Imperial Records\Projects`
- AI prompts, model behavior notes, or agent experiments that belong in `D:\Imperial Records\Labs\AI`
- learning reflections that belong in `Learning & Skills`
- broad computer-science concepts that belong in `Notes` or another subject folder

## How To Use It

- keep one tool or software family per child folder
- keep commands and setup steps close to the tool they belong to
- move tool-specific reference here when it stops being a learning note
- link important guides from [[Tools and Software Reference MOC]]

## Review Rhythm

- Review when a tool starts collecting repeated notes or duplicated command lists.
- Split a tool into child buckets only when it improves lookup speed.
